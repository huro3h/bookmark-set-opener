# Bookmarks Launcher

複数のブックマークを、ワンクリックでまとめて新しいタブに開く Chrome 拡張 (MV3)。

毎朝開くサイト一式や、作業ごとの資料をすぐに全部開くためのもの。
別々のフォルダにあるブックマークを選んで「セット」にまとめておく(ブックマークの整理はそのまま)。

## 機能

- ツールバーのアイコンを押すとセットが並び、押すと中身を全部開く。右上の歯車で設定画面を開く
- セットごとに「バックグラウンドで開く」(開いたタブに切り替えず、今のタブのまま)を選べる。設定画面のセット一覧でチェックする
- よく使うセットやフォルダは5つまで「スロット」に割り当てて、ショートカットキーで直接開ける
- セットをファイルにエクスポート/インポートして、退避・復元や別の PC・ブラウザへの持ち運びができる
- 20 個以上のタブを開くときは、もう一度押して確認する
- 設定画面の複製ボタンで、セットを「〜 のコピー」として複製できる(中身が少しだけ違うセットを作るときに使う)
- 設定画面でセットを削除すると「〜を削除しました [元に戻す]」と出て、数秒の間なら元に戻せる

開く場所は、最後に使っていたウィンドウの末尾。最初のタブが選択された状態になる(バックグラウンドで開くセットは除く)。

ポップアップの行の右には、そのセットを開くショートカットキー(設定している場合だけ。例: `⇧⌘1`)と、開くタブの数が出る。

## セット

ポップアップの歯車 →「新しいセット」で、名前を付けてブックマークを選ぶ。
編集画面にはブラウザ上部のブックマークバーがそのまま再現されていて、普段のブックマークバーの感覚で選べる
(画面はブラウザの横幅いっぱいに広がる)。

- ブックマークを押すと選択/解除。選択中のものは枠とハイライトで示す
- フォルダを押すとブラウザと同じドロップダウンのメニューで中身が開き、そこでも押して選べる(続けて選べるようメニューは開いたまま)
- メニューの「このフォルダをすべて選択」でサブフォルダを含めてまとめて選べる

バーの下には「n 件を選択中」として選んだブックマークの一覧(ファビコン・タイトル・URL)が出て、× で選択を外せる。
この一覧の並びがタブを開く順になる。新しく選んだものは末尾に足され、左端の ⠿ をドラッグして並べ替えられる。
Undo / Redo・キャンセル・保存のボタンは、見出しと名前の欄と同じ行の右端にある。

選択の操作は **Undo / Redo** できる(↶ ↷ のボタン、または `⌘Z` / `⇧⌘Z`。Windows などは `Ctrl+Z` / `Ctrl+Y`)。
「このフォルダをすべて選択」を押し間違えたときも1回で戻せる。名前の入力欄にいる間は、文字入力の Undo になる。
設定画面のセット一覧も、左端の ⠿ をドラッグして並べ替えられる(ポップアップでの表示順)。

- **ブックマークを編集するとセットも追従する。** タイトルや URL を直したり別のフォルダへ移したりしても、セットはそのブックマークを指したまま
- **ブックマークを削除しても、セットからは消えない。** 保存してある URL のまま開く。設定画面と編集画面の選択中の一覧に「ブックマークにない」と出るので、不要なら一覧の × で外す
- 同じ URL のブックマークを登録し直すと、自動的にそちらに結び付く

### エクスポート/インポート

設定画面の「エクスポート」で JSON ファイルに書き出し、別の環境の「インポート」で読み込む。

- インポートしたセットは、URL でその環境のブックマークと照合する。同じ URL のブックマークがあればそれに結び付き、以降は上と同じように編集に追従する。なければ保存されていた URL で開く
- 同じファイルを読み直すと、セットは重複せず置き換わる
- セットの並び(ポップアップの表示順)とセットの中の並び(開く順)もファイルに入る。取り込んだセットはファイルの並びのまま
  後ろにまとめて入り、ファイルにないセットは今の並びのまま前に残る。全部を書き出したファイルを戻せば、書き出したときの並びに戻る
- 「バックグラウンドで開く」の設定もファイルに含まれる
- ショートカットのスロットの割り当てはファイルに含めない(環境ごとに設定する)

ブックマークの内部 ID は環境(PC・ブラウザ・プロフィール)ごとに別々に振られるため、ファイルには含めていない。
同じ番号が別の環境では別のブックマークを指すことがあり、取り違えの元になるため。

ブックマークレット(`javascript:` で始まるもの)は開かない。

## ショートカットキー

初期状態ではキーを割り当てていない。

1. 設定画面の「ショートカットキー」で、スロット1〜5にセットかフォルダを選ぶ
   フォルダを割り当てた場合は、そのフォルダ直下のブックマークを開く(サブフォルダの中身は開かない)
2. 「ショートカットキーを設定する」で `chrome://extensions/shortcuts` を開き、各スロットにキーを割り当てる

開けなかったとき(未割り当て・削除された等)は、アイコンに赤い「!」が数秒出る。

## インストール

1. `chrome://extensions` を開く
2. 「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ

使う権限は `bookmarks`(ブックマークの読み取り)、`storage`(セットと設定の保存)、`favicon`(セット編集画面でブラウザがキャッシュしているファビコンを表示)だけ。外部への通信はしない。
